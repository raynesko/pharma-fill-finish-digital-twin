# Five-slide summary: speaking script (T7.2.1)

Generated by `python -m ffdt.experiments.slides`; do not edit by hand. 243 words, about 97 s at 150 words per minute (target: 2 minutes spoken). Simulated, benchmark-parameterized; not plant data. Slides: [`slides.pdf`](slides.pdf) (source [`slides.html`](slides.html)).

**Slide 1.** Sterile fill-finish lines are expensive, so plants want more good vials from the same line. I compared four common ideas: a second inspection machine, batch size, staffing, and faster changeovers, and asked which station really limits the line.

**Slide 2.** I built a discrete-event simulation of a seven-station vial line for one week, with random breakdowns, minor stops, rejects, shared staff and QA release. The parameters come from public benchmarks, not plant data, and I wrote down the scenarios and decision rules before running anything.

**Slide 3.** To trust it, I checked it against queueing theory and availability formulas, and the theory fell inside every confidence interval. I also moved each uncertain parameter up and down on its own, 24 runs, and the filler stayed the constraint every time. My tests caught two model bugs along the way, which I fixed and documented.

**Slide 4.** The baseline line OEE is 57 percent. Changeovers eat 27 percent of the filler's scheduled time, and the filler is the constraint by all 4 methods. Cutting changeovers in half adds about 25 percent more good vials. A second inspection machine adds 0.2 percent, which is not statistically different from zero, because inspection is not the constraint.

**Slide 5.** So I would start with a SMED project across the whole line, then add one line operator, about 3.5 percent more, and skip the inspection machine. With real data, I would fit breakdown and repair times from the historian and time a real changeover before committing money.
