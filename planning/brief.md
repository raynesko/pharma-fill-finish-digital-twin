# Project brief 1: Pharma Fill-Finish Digital Twin (as provided)

Discrete-event simulation of a sterile fill-finish line (vial washing, depyrogenation, filling, capping, inspection, labeling, packaging). Include realistic stochastic downtime, changeovers, batch sizes and QA hold times. Build with SimPy (or Simio-like tool) with an interface where a user can change parameters and see throughput, OEE, utilization and queue times. Run a scenario study (add an inspection station, change batch size, change staffing, reduce changeover time) and identify the bottleneck.

Target roles: process engineering, manufacturing engineering, continuous improvement.

Note: the pasted brief was truncated in places ("Simulit..."); the text above is the legible content. Decision: SimPy, not a commercial tool.
